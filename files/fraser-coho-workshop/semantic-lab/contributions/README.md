# Term contribution practice

Chapter 12 uses this folder after the real human graph, dictionary, and peer review.

- `../worksheets/term-request.md`: the canonical blank request/source-question worksheet.
- `source-clarification-example.md`: filled, unsubmitted illustration; no human approval or new shared-term absence claim.
- `preview-term-requests.R` / `.py`: read the supplied seeded evidence, check preparation, and write candidate previews into a fresh `output/` folder. No retrieval, live AI, or issue submission.
- `recorded-gap-preview.csv` / `recorded-preview-notes.md`: recorded detection/render results for the spreadsheet lane, with versions and evidence limits.

Automatic request titles are deliberately inspected as provisional text. Keep the manual search log and actual review decisions; neither a candidate list nor this folder authorizes publication or ontology changes.
