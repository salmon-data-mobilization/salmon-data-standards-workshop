## Salmon Data Integration Workshop

Start with the terms your organization uses. Learn to write precise definitions, build a controlled vocabulary, connect local meanings to shared concepts, and package data so the next team can reuse that preparation.

The teaching materials and core software tools are free to use. You can explore the materials now or ask Brett about future training sessions.
